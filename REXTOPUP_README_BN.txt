REX TOPUP — Admin Control Update

এই প্যাকেজে রয়েছে:
- REXTOPUP_Admin_Fixed.html: আপডেট করা single-file UI prototype.
- UPDATE_NOTES_BN.txt: কী আপডেট হয়েছে ও সীমাবদ্ধতা।
- REXTOPUP_README_BN.txt: ব্যবহার নির্দেশিকা।
- REXTOPUP_Dynamic_Theme_Setup.zip: আগের PHP/MySQL dynamic theme starter; এটি পুরো website-এর backend নয়।

ব্যবহার:
1. HTML ফাইলটি ব্রাউজারে খুলে Admin Control Center পরীক্ষা করুন।
2. Banners & Notice-এ logo, notice, hero text এবং banner image URL সেট করুন।
3. Products & Rates-এ product name/description/price/icon/image URL এবং package preview বদলান।
4. UI Elements-এ পাবলিক পেজের অনেক button/link/heading/paragraph-এর লেখা, visibility এবং link URL বদলান।
5. Site Settings-এ site name, support URL/email ও footer text preview সংরক্ষণ করুন।

সীমাবদ্ধতা:
এটি এখনো localStorage-ভিত্তিক front-end preview. পরিবর্তন এই ব্রাউজারেই থাকে। সবার জন্য live update করতে পুরো website-এর প্রয়োজন অনুযায়ী secure backend/API ও database integration করতে হবে। সংযুক্ত PHP/MySQL starter theme settings-এর ভিত্তি হিসেবে দেওয়া, পূর্ণ e-commerce backend নয়। Live payment, account authentication, wallet, UID lookup ও auto delivery সক্রিয় নয়।
